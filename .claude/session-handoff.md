# Session handoff — Anjaz (v0.5.0)

## الحالة
- الفرع feature/v050-polish: إصلاح الطابور، تسجيل بنمط واتساب، Whisper، فيديو، جرس، شعار متحرك، إنشاء حساب ببريد، إصدار في التذييل.
- Worker منشور بتوكن المستخدم (مرتين) وD1 فيه جداول الوسائط الجديدة. اختبارات: 69 تطبيق + 12 Worker، وassembleRelease يعمل محلياً.

## قرارات
- Whisper base int8 يُنزَّل عند أول استخدام (~160MB) ثم يعمل بلا إنترنت؛ مكتبة sherpa-onnx تُنزَّل ببصمة في Gradle (app/libs ليست في Git).
- الفيديو: ≤90 ثانية، يُضغط تحت 9MB، حد Worker 10MB.
- فشل رسالة لا يوقف الطابور؛ الانقطاع فقط يوقف الجولة.

## مفتوح
- لم يُجرَّب على جهاز: الإملاء، الفيديو، التسجيل الجديد، الجرس.
- أسرار GitHub CLOUDFLARE_API_TOKEN وCLOUDFLARE_ACCOUNT_ID فارغة؛ التوكن الذي أُرسل في المحادثة يُدوَّر.
- تفريغ الصوت بـ base متوسط الدقة للعربية؛ small أدق وأبطأ (WhisperModel.NAME).

## الخطوة التالية
