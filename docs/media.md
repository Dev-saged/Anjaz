# تصميم الوسائط

- المرسل يضغط الملف محلياً ويحفظه في مجلد التطبيق ثم يرفعه عبر الـ Worker (PUT /v1/media، مفتاح تكرار = mediaId) قبل إرسال الرسالة.
- المستلم يُنزّله إلى مجلد التطبيق (صور وصوت تلقائياً، ملفات بالضغط) ثم يرسل تأكيداً (POST /v1/media/:id/ack).
- بعد تأكيد كل الأعضاء غير المرسل يُجدول الحذف بعد ساعة؛ الحد الأقصى للبقاء 14 يوماً ثم تظهر «انتهت صلاحية الملف».
- الخطة البديلة: عند فشل الرفع/التنزيل تبقى الرسالة في الصندوق الصادر وتُعاد المحاولة؛ مؤقتات `.part` والملفات اليتيمة تُنظَّف بـ MediaRepository.cleanOrphans.
