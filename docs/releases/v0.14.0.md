# v0.14.0

## الإضافات
- المربعات الفرعية: يتبع المربع مربعاً رئيسياً من حقل «التبعية» في تعديل المربع، أو من زر «مربع فرعي جديد داخل …».
- تحويل منطقة إلى مربع صار يقبل منطقة فيها مربعات: تصبح مربعاً رئيسياً ومربعاتها فرعية داخله، أو تُدمج تحت مربع موجود («تحت مربع موجود: …»).

## المميزات
- الإحصائيات والأوزان النسبية والتوزيع تعرض المربعات الرئيسية فقط، وأرقام كل رئيسي تشمل فرعياته.
- التوزيع على ثلاثة مستويات: المربعات الرئيسية ← داخل الرئيسي بين مخيماته المباشرة ومربعاته الفرعية ← مخيمات كل فرعي. المجموع يطابق الكمية دائماً.
- الدليل يعرض الفرعيات داخل رئيسيها بمسؤولها ومخيماتها وأرقامها، ومهمة توزيع المربع الرئيسي تتضمن تفصيل فرعياته.
- القوائم تعرض الاسم الكامل «سنابل › الأمل».
- حذف المربع الرئيسي ينقل فرعياته ومخيماتها معه للسلة، والاسترجاع يعيدها.

## الإصلاحات
- عدد المربعات في الرئيسية يحسب الرئيسية فقط.
