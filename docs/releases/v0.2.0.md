## الإضافات
- تسجيل الدخول باسم مستخدم وكلمة مرور، وجلسة محفوظة، وأدوار خمسة بصلاحيات في الواجهة.
- مزامنة Firestore (دفع من الصندوق الصادر بالترتيب + سحب لحظي) مع WorkManager.
- نداء الاستغاثة (ضغط مطوّل + موقع اختياري) وتسلسل مفتوح ← استلام ← معالج، وشريط تنبيه في الرئيسية.
- محادثات فردية مع إيصالات قراءة، وتخزين محلي أولاً ثم إرسال.
- دليل المناطق والمربعات والمخيمات، وإدارة الحسابات (إنشاء، إعادة ضبط، تعطيل) عبر Worker.
- إشعارات FCM بقناتين (عامة واستغاثة) وفتح الشاشة المناسبة من الإشعار.
- تقرير المهام PDF وExcel، ونسخ احتياطي JSON واستعادة بالدمج، وسجل العمليات للقادة.
- الخلفية: قواعد Firestore (19 اختباراً) وWorker (9 اختبارات) ونشر عبر GitHub Actions.

## المميزات
- يعمل دون إنترنت: كل العمليات محلية أولاً، وتُدفع عند عودة الاتصال بمفتاح تكرار فلا تتكرر.
- Room v3 بترحيلات مرقّمة (1→2→3) مختبرة على بيانات حقيقية.
- العزل بين المناطق والمربعات في القواعد والـ Worker لا في الواجهة.

## الإصلاحات
- ثغرة readBy: كان يمكن إضافة معرّف مستخدم آخر كقارئ؛ صارت المقارنة بالاتحاد الدقيق.
- الإنشاء يدفع الحالة الأولية (NEW/OPEN) وعمليات الحالة تدفع حالتها المسجلة، فلا ترفضها القواعد عند العمل دون اتصال.
