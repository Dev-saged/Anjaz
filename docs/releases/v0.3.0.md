## الإضافات
- تحديث ذاتي كامل: بانر علوي فخم وإشعار عند وجود نسخة أحدث، وورقة «ما الجديد» بملاحظات الإصدار.
- تنزيل في خدمة أمامية بنسبة حية يستمر بعد إغلاق التطبيق، ثم «تم التحميل» وزر تثبيت في البانر والإشعار.
- مجلد التطبيق على الهاتف (updates وbackups وexports)، والنسخة الاحتياطية تُحفظ فيه أيضًا.
- فحص تلقائي عند الفتح وكل 6 ساعات في الخلفية، وزر «التحديثات» في شاشة المزيد.
- README عرضي جديد، وبطاقة «المطوّر» وحسابات التواصل في شاشتي الدخول والمزيد، وإعادة تصميم شاشة الدخول (بطاقة مرتبة وخط أصغر).

## المميزات
- استئناف التنزيل عبر Range وإعادة محاولة متدرجة فلا يتعثر عند ضعف الاتصال.
- ثلاث طبقات فحص مستقلة من GitHub، فلا يخفي حجبٌ واحد النسخة الجديدة.
- لا يُثبَّت إلا ملف بنفس اسم الحزمة ورقم أحدث، ويُحذف الـAPK تلقائيًا بعد التثبيت.
- كل push على main ينشر Release جديدًا بـAPK وversion.json (يلزم أسرار التوقيع).
