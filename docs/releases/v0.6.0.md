# v0.6.0

## الإضافات
- شاشة «ما الجديد» داخل التطبيق (المزيد) بسجل الإصدارات.
- تنظيف يومي تلقائي للملفات المؤقتة وملفات الوسائط اليتيمة.

## المميزات
- حالات فارغة موحّدة بأيقونة وشرح في المحادثات والمهام والمربعات والسجل والحسابات.
- الاختبار الذاتي (#test) يغطي صيغ اسم المستخدم وإصدار قاعدة البيانات.

## الإصلاحات
- التنظيف لا يمس ملفات التنزيل الجارية (يتجاهل ما عمره أقل من ساعة).
