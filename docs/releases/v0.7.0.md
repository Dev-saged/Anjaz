# v0.7.0

## الإضافات
- تعديل بيانات الحساب: الاسم والدور والمنطقة والمربع.
- حذف حساب نهائياً: يُحذف الدخول ويُخفى من القوائم، وتبقى مهامه ورسائله في السجل.

## المميزات
- التعطيل والتفعيل المؤقت كما هو، مع نافذة تأكيد قبل الحذف.
- كل تعديل وحذف يُسجَّل في سجل العمليات.

## الإصلاحات
- لا يمكن حذف حسابك أو تغيير دورك بنفسك، ولا يُدار حساب محذوف.
