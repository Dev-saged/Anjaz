# v0.8.0

## الإضافات
- خريطة حيّة (osmdroid/OSM): أشخاص، نقاط، مساكن مسؤولين، بلاغات SOS، إنجازات وتأخيرات بنبضات
- تسجيل الوصول بالموقع (Presence)
- مكالمات صوتية WebRTC (واحد لواحد وغرفة حتى 4)
- مهام متكررة (يومي/أسبوعي) بجدولة الـ Worker
- تقرير أسبوعي: إشعار + PDF
- صور قبل/بعد للمهمة
- قفل التطبيق بالبصمة أو رمز الجهاز
- بحث شامل (مهام، أشخاص، ساحات، مخيمات، رسائل)
