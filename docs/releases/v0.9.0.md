# v0.9.0

## الإضافات
- مكالمة صوتية بأيقونة هاتف (بدل أيقونة الفيديو)
- مركز التنزيلات والمكوّنات في «المزيد»: حالة ونسبة وإعادة محاولة وحذف، مع إشعار تقدّم يختفي عند الانتهاء
- اختيار حجم نموذج الإملاء: خفيف / متوازن / دقيق
- مركز المزامنة: شرح كل عملية معلّقة مع إعادة المحاولة أو التجاهل

## المميزات
- تسجيل صوتي بنمط واتساب: زر يتحرك مع الإصبع، قفل بالسحب للأعلى، موجة حية، تلميح عند الضغطة القصيرة
- مشغّل صوت تفاعلي: حلقة تقدّم دائرية، موجة قابلة للتقديم، إيقاف مؤقت، سرعة 1× / 1.5× / 2×
- نسبة التنزيل تظهر على الرسالة الصوتية أثناء تحميلها
- زر الإملاء مميّز بأيقونة خاصة عن زر التسجيل
- الرئيسية: بطاقة مخيمات واحدة وخريطة بنبض ورادار ومسار متحرك

## الإصلاحات
- بطاقة «عمليات بانتظار المزامنة» لم تكن تفعل شيئاً عند الضغط
